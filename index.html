Configuração da nuvem

Configuração única do administrador.

Por que existe esta etapa?
Para os dados realmente ficarem em uma conta e abrirem em outro computador, eles precisam de um banco de dados online. Esta versão usa Supabase, sem instalar programa algum no PC.
  1. Crie um projeto gratuito no Supabase.
  2. Abra o editor SQL do projeto e execute o arquivo CONFIGURAR_NUVEM.sql que acompanha este sistema.
  3. Copie a Project URL e a chave anon/publishable nas configurações de API do projeto.
  4. Cole os dois dados abaixo e salve.

A chave publishable foi feita para aplicativos no navegador. Projetos antigos também aceitam a chave anon legada. Nunca use secret ou service_role aqui.
